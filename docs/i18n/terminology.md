# Terminology / 术语表

This table is bilingual by construction and has no separate translation. / 本表本身为双语，不另建译文。

| English | 简体中文 | Usage / 用法 |
|---|---|---|
| Harness | Harness | Product name; do not translate. / 产品名，不翻译。 |
| Host | Host（主机） | The computer running Harness and the Remote plugin. / 运行 Harness 和 Remote 插件的电脑。 |
| Client | 客户端 | The iOS application. / iOS 应用。 |
| Remote Server | Remote Server（远程服务端） | Registration, discovery, coordination, and relay service. / 注册、发现、协调与中继服务。 |
| Session | 会话 | A Harness conversation and its durable events. / Harness 对话及其持久事件。 |
| Workspace | 工作区 | Project context on the Host. / Host 上的项目上下文。 |
| Approval | 审批 | A response to a Host permission request. / 对 Host 权限请求的响应。 |
| Relay | Relay（中继） | A transport path; distinct from the encryption layer. / 一种传输路径，与加密层分别描述。 |
| Noise | Noise | Protocol name; preserve the exact suite identifier. / 协议名，保留完整套件标识。 |
| Pinning | 公钥固定 | Remembering and checking a device's trusted public key. / 记住并核验设备受信任的公钥。 |
| Stream | 流 | An incremental sequence of values or events. / 增量返回的值或事件序列。 |
| Synchronization record | 同步记录 | Reviewed content hashes in a `.i18n.yaml` sidecar. / `.i18n.yaml` 文件中已审阅内容的哈希。 |
| Release rehearsal | 发布预演 | Build and verify artifacts without publishing them. / 构建和验证产物，但不发布。 |
