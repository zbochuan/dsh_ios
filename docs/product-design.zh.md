## 方向与证据

2026-11-03 的修订将宣传欢迎页改为安静的对话客户端。用户认为旧设计不好看、AI 味太重，并提出参考 Claude 和 ChatGPT。本页负责修订后的交互意图与验收条件。[可交互 HTML 评审页](../design/product-review.html)已替换为当前的对话、历史、审批和设备发现入口设计。它是不依赖外部资源的浏览器示意，状态仅保留在本地，不发起网络请求；其布局和交互不能证明原生 iOS 行为。

[参考研究](../design/reference-study.json)记录了美国 App Store 官方元数据、实际查看的 17 张 iPhone 与 2 张 iPad 截图、证据路径、哈希与十项观察。获取时列表版本为 Claude `1.261030.19` 和 ChatGPT `1.2026.293`；截图拍摄日期及其对应二进制版本未知。这些是静态宣传图，不是运行证据。观察对象是构图中的应用界面，不包含广告标题、照片和渐变；没有确认完整展开的通用历史抽屉或动效行为。

参考研究保留了部分证据的来源 URL 与哈希，并非截图归档包。其中的本地元数据和图片路径指向被 Git 忽略的 `build/references/` 目录，新克隆的仓库不包含这些文件。可以尝试通过 URL 重新获取，用哈希比对保留的文件内容，但不能保证链接持续有效或后续下载内容相同。HTML 评审页不依赖这些下载文件，也不包含参考截图资源。

| 可见证据 | DSH 决策 | 边界 |
|---|---|---|
| 小型导航控件围绕较大的对话区域 | 行内标题、历史入口与新对话操作；不设宣传首页 | 历史 sheet 和 iPad 侧栏是 DSH 的设计选择，不是截图所能证明的行为 |
| 中性用户气泡与无外框助手段落 | 画布交给内容；不重复显示助手标记 | 原生字号、间距与可访问性仍需验证 |
| 底部单一输入框与相邻控件 | 一个多行输入框及发送/停止；保留键盘安全区域 | 模型、语音和附件未支持前不显示对应控件 |
| 紧凑的回复操作与结构化文件/审批对象 | 复制紧邻回复；仅为实际待确认请求保留容器 | 截图外观既不证明执行，也不证明审批确认 |

[应用架构](architecture.zh.md)负责已实现能力与协议边界；[开发与 CI/CD](development.zh.md)负责构建和设备证据。下文描述源码意图，不代表已完成原生可用性或可访问性评估。不宣称用户研究结果或改善百分比。

## 导航与对话

假设的移动任务是在离开电脑时阅读结果、补充指令或决定一次阻塞操作。执行、模型凭据与项目文件留在电脑。当前客户端可以在本地演示对话交互并发现真实电脑，还不能继续真实 Host 会话。

| 情境 | 主要内容与操作 | 上下文与返回路径 |
|---|---|---|
| 首次打开 | DSH 标题、一句简短邀请、“试用本地对话”与“登录并发现电脑” | 选择演示前没有可输入编辑器或新对话控件 |
| 本地对话 | 消息、一个输入框、新对话 | 标题中的紧凑“本地演示”可打开说明；左侧工具栏按钮打开历史 |
| 历史记录 | 搜索标题/工作区，按最近活动排序，显示草稿预览与待确认状态 | 选择一行回到该对话；电脑和设置作为次级入口 |
| iPad | 历史侧栏与对话详情 | 次级页面通过原生 sheet 打开，不替换已选对话 |
| 电脑 | 账号来源、真实发现结果、重试或空态 | 设备详情说明状态由服务报告；不开放远程项目或聊天控件 |
| 设置 | 外观、Remote 账号、演示退出/恢复与关于 | 返回或关闭后回到已有对话 |

进入演示直接打开空白对话；示例保留在历史中，其中包含一条审批示例。新对话保留原草稿，并尽可能复用尚未输入的空白对话。草稿按会话隔离。退出演示、打开连接页与登录账号均保留本次打开期间的本地历史与草稿；重新进入时恢复所选对话。存储仍在内存中，进程终止后不保留。退出不删除内容，因此无需确认弹窗。

助手文字直接显示在画布上，用户文字使用克制的气泡，每条完成的回复下方提供复制。思路与活动默认折叠。待审批操作在所属会话中可见，也可从暂时禁用的发送按钮上方打开。增量文字不应把正在阅读旧内容的人拉回底部；保留“回到最新”操作。不为模仿其他产品而增加占位控件。

## 模式与连接边界

对话标题只保留一个持续可见的紧凑“本地演示”标识。点开说明预设回复、仅记录本地选择、不执行命令，同时说明内存生命周期和退出/恢复语义。避免在消息顶部、输入框脚注和每条消息中重复完整警告。预设回复的简短开头与审批结果属于就地信息。

| 状态 | 必须表现 |
|---|---|
| 未登录 | 解释实际登录目的地，并要求有效 HTTPS 根地址、账号和密码 |
| 加载或恢复中 | 显示进度，避免重复请求 |
| 已登录但发现失败 | 保留账号上下文并显示错误与重试，不出现成功空列表提示 |
| 发现成功但为空 | 说明账号/服务需一致及电脑插件需启用；允许刷新 |
| 电脑在线/离线 | 仅显示服务端报告状态；不编造最近在线时间、受信任徽章或加密状态 |
| 登录完成 | 关闭登录页并回到原账号/电脑页面，不重置本地对话 |

当前连接界面调用已有登录、恢复、刷新和退出登录 API，不模拟设备发现。完整会话支持仍需要 Control/Relay、独立 Host 身份核验、Noise、能力协商、RPC 与流。未来发送和审批响应必须区分已提交、已确认与结果未知；不自动重放状态未知的操作，也不因 iOS 进入后台就认定电脑任务已停止。

## 有上下文的审批

审批属于原对话，不设独立主标签。详情先展示电脑、完整工作区路径、可选择的准确命令、原因与已说明的影响，再显示允许一次和拒绝。演示电脑名称明确标为示例。范围描述是说明，不是安全保证；缺失范围时明确标注。不提供永久授权或滑动批准。

关闭 sheet 会保留有效且未回答的请求。处理请求只消费一次标识，记录本地选择，并在原对话显示结果；文字不宣称命令已执行。停止生成、退出演示或后台失效后不能授权旧请求。已经打开的 sheet 同时检查当前标识与等待状态，再启用操作。失效请求会在消息中留下简短说明，草稿保持不变。真实过期事件与 Host 确认仍待实现。

## 原生呈现与验收

采用系统文字样式、语义控件、原生导航/sheet 与适配键盘的输入框。DeepSeek 蓝只作为聚焦、选中和发送等功能强调。保持中性画布、克制气泡和可读正文；避免通用闪光标记、渐变、装饰徽章和编号功能卡片。不复用 Claude/ChatGPT 品牌、截图像素、模型名称或未支持能力。视觉与动效专项必须在原生屏幕验证这一方向；静态参考不能决定动画方案。

| 近期检查 | 验收条件 |
|---|---|
| 首屏与聊天 | 无宣传大标题或功能卡片堆叠；演示明确；只有进入演示后出现唯一输入框 |
| 导航与草稿保留 | 输入草稿、新建/选择另一个对话、退出/恢复演示、取消登录；原草稿始终留在原会话 |
| 审批 | 查看位置/范围、不作选择关闭，再允许或拒绝；请求只消失一次且本地结果保留；过期/被替换请求不能处理 |
| 设备发现 | 加载、错误、空列表、在线与离线可区分；错误不转换为虚构电脑或可用远程聊天 |
| 阅读与输入 | 验证小屏 iPhone 和 iPad、键盘、长中文、命令选择、历史滚动与回到最新 |
| 可访问性与动效 | 验证 44 点主要目标、最大可访问字号、VoiceOver 顺序、深浅色对比度与 Reduce Motion；不逐字触发整页动画 |

[UI 测试](../AppUITests/DSHUITests.swift)覆盖发送/停止、历史与演示退出的草稿保留、两种审批选择、关闭未处理审批以及仅设备发现入口。[会话测试](../Packages/DSHCore/Tests/DSHCoreTests/ConversationTests.swift)覆盖旧请求拒绝、一次消费、失效反馈与草稿保留。[开发与 CI/CD](development.zh.md)记录已完成的构建、模拟器结果、真机启动，以及浏览器和视觉检查的边界。源码测试或可触达性断言通过不代表完整的原生视觉或无障碍验收；真实 Host 互通仍未验证。
