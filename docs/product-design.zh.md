## 方向与证据

2026-11-03 的修订先将宣传欢迎页改为安静的对话客户端：用户认为旧设计不好看、AI 味太重，并提出参考 Claude 和 ChatGPT。同日的任务控制台修订进一步把任务而非对话作为应用的基本单位：手机是用户电脑上 Agent 的随身控制台，对话只是任务中的一种交互。它依据在项目对话中评审的线框图（首页、任务、审批、抽屉、配对和设置），这些线框图不保存在本仓库中。本页负责由此得出的交互意图与验收条件。[可交互 HTML 评审页](../design/product-review.html)仍展示较早的对话优先设计。它是不依赖外部资源的浏览器示意，状态仅保留在本地，不发起网络请求；它和线框图都不能证明原生 iOS 行为。

[参考研究](../design/reference-study.json)记录了美国 App Store 官方元数据、实际查看的 17 张 iPhone 与 2 张 iPad 截图、证据路径、哈希与十项观察。获取时列表版本为 Claude `1.261030.19` 和 ChatGPT `1.2026.293`；截图拍摄日期及其对应二进制版本未知。这些是静态宣传图，不是运行证据。观察对象是构图中的应用界面，不包含广告标题、照片和渐变；没有确认完整展开的通用历史抽屉或动效行为。

参考研究保留了部分证据的来源 URL 与哈希，并非截图归档包。其中的本地元数据和图片路径指向被 Git 忽略的 `build/references/` 目录，新克隆的仓库不包含这些文件。可以尝试通过 URL 重新获取，用哈希比对保留的文件内容，但不能保证链接持续有效或后续下载内容相同。HTML 评审页不依赖这些下载文件，也不包含参考截图资源。

## 导航与对话

假定的移动端任务是：离开电脑时查看每台电脑上的 Agent 在做什么，回应等待用户处理的事项，并发起或调整任务。执行、模型凭据和项目文件留在电脑上。当前客户端可在本地展示示例任务并发现真实电脑，但还不能列出或继续真实的 Host 会话。

| 场景 | 主要内容与操作 | 上下文与返回路径 |
|---|---|---|
| 首次打开 | 一句用途说明、“连接电脑”卡片和一个示例任务 | 打开示例前没有输入框或新任务控件 |
| 首页（任务） | 先显示“等你确认 · N”卡片，再按电脑分组列出任务的状态、用时和最新动态；输入框带电脑、项目和权限标签 | 菜单按钮或从左边缘轻扫打开抽屉；离线电脑说明重连后任务会继续 |
| 抽屉 | 搜索任务、全部任务、按电脑和项目分组并带运行中与等你确认圆点的任务；长按可重命名、归档或删除 | 底部行打开电脑和设置；在 iPad 上抽屉就是分栏侧栏 |
| 任务详情 | 标题及电脑和项目、消息、折叠的动态、改动卡片和终端卡片、带“停止”的运行状态行，以及带模型和权限菜单的输入框 | 返回到列表；更多菜单提供新任务、重命名、归档和删除 |
| 连接电脑 | 二维码取景框占位、代码文件和密钥留在电脑上的说明、可复制的配对命令 | “手动输入”打开现有 Remote 登录；示例任务一步即达 |
| 设置 | 电脑、通知偏好、新任务默认值和通用（外观、账号、关于） | 账号页保留退出登录和连接恢复 |

打开示例会载入示例任务：一个运行中、一个等待审批、一个已完成并带改动、一个失败、一个位于离线电脑。唯一的示例说明放在已完成的示例任务中；标题、页脚和设置不重复演示警告。新任务会复用未改动的空白任务；草稿按任务保存，在导航、面板和取消登录后保留。数据只保存在内存中，进程结束后不保留。

助手文字留在画布上并支持行内 Markdown，用户文字使用中性气泡，动态折叠为一行，例如“读了 3 个文件 · 改了 2 个 · 运行 1 条命令”。复制和分叉位于已完成回答下方；重试只出现在最新回答上。分叉会把截至该消息的对话复制为新任务。新内容不应把正在阅读旧内容的用户拉走；保留“回到最新”操作。附件和直接听写是可见占位，不假装可用。

## 模式与连接边界

示例任务只在示例内部说明一次。通知开关在电脑能发送事件前只保存偏好；配对命令 `dsh pair` 和扫码是 ds-harness-remote 尚未提供的提议。手机提供三种权限模式：每次询问、自动改文件和计划模式，从不提供跳过所有确认的模式。

| 状态 | 必要行为 |
|---|---|
| 未登录 | 说明实际登录目标，并要求有效的 HTTPS 源、账号和密码 |
| 加载或恢复中 | 显示进度状态；防止重复请求 |
| 已登录但发现失败 | 保留账号上下文并显示失败与重试，不能显示为成功的空列表 |
| 发现成功但为空 | 说明需匹配账号/服务并启用电脑插件；允许刷新 |
| 电脑在线/离线 | 只显示服务端报告的状态；不编造最后在线时间、可信标识或加密状态 |
| 登录完成 | 返回电脑列表，不重置本地任务或草稿 |

当前连接界面调用现有的登录、恢复、刷新和退出登录 API，不模拟设备发现。完整会话支持仍需要 Control/Relay、独立的 Host 身份核验、Noise、能力协商、RPC 和流。未来的发送和审批响应必须区分已提交、已确认和结果未知；不自动重放不确定的操作，也不能仅因 iOS 进入后台就断定电脑上的任务已停止。

## 情境中的审批

审批属于它所在的任务。它会出现在首页顶部的卡片、任务记录中的卡片以及任务输入框上方的状态行中，三者打开同一个面板。面板显示操作、等待中的任务与时间、可选中的完整命令、电脑、工作区和 Agent 说明，然后提供“允许这一次”“拒绝”和“拒绝并说明”。页脚显示并可更改本任务的权限模式。说明不是安全保证。不提供永久授权或滑动批准。

关闭面板会让有效请求保持未回答。处理请求会一次性消费其标识，记录本地选择（包括说明），并在同一记录中显示结果；措辞从不声称已执行。停止任务或应用进入后台都不能授权旧请求。已打开的面板会同时检查当前标识与等待阶段后才启用操作。失效的请求会在记录中补充简短说明，草稿保持不变。真实的过期事件和 Host 确认仍是后续工作。

## 原生呈现与验收

使用系统文字样式、语义化控件、原生导航/面板和适配键盘的输入框。配色为白色画布、墨色文字和中性表面；蓝色只表示运行中的工作和可点按链接，琥珀色只表示等待用户处理的事项，绿色表示成功，红色表示失败。命令和路径使用等宽字体；终端输出和配对页面使用深色表面。避免闪光品牌元素、渐变、装饰徽章和编号功能卡片。不复用 Claude/ChatGPT 品牌、截图像素或尚不支持的能力。

| 近期检查 | 验收条件 |
|---|---|
| 首屏与首页 | 没有宣传主视觉；只有连接和示例入口；等你确认的卡片在前，任务按电脑分组 |
| 导航与草稿保留 | 输入草稿，新建另一个任务，回到首页，打开面板并取消登录；原草稿仍在原任务中 |
| 审批 | 查看命令和位置，不作决定直接关闭，然后允许、拒绝或拒绝并说明；请求只消失一次并保留本地结果；过期请求无法处理 |
| 设备发现 | 加载、错误、空列表、在线和离线保持区分；不把错误转换为虚构设备或可用的远程任务 |
| 阅读与输入 | 验证小尺寸 iPhone 和 iPad、键盘、长中文文本、可选中的命令、改动卡片和终端卡片以及“回到最新” |
| 无障碍与动效 | 验证 44 点主要点击区域、最大辅助字号、状态和改动行的 VoiceOver 标签、浅色/深色对比度，以及运行指示和抽屉的减弱动态效果 |

[UI 测试](../AppUITests/DSHUITests.swift)覆盖发送/停止、从首页发起任务、在新建任务和取消登录后保留草稿、允许、拒绝和拒绝并说明、首页等待卡片、进入后台后失效、连接与配对入口、不含跳过选项的权限菜单、分叉、抽屉搜索和最大辅助字号。[对话测试](../Packages/DSHCore/Tests/DSHCoreTests/ConversationTests.swift)和[任务测试](../Packages/DSHCore/Tests/DSHCoreTests/TaskTests.swift)覆盖过期请求拒绝、一次性消费、说明、任务状态、分组、搜索、重试、分叉和时间格式。[开发与 CI/CD](development.zh.md)记录已完成的构建、模拟器结果、设备启动以及浏览器和视觉检查的局限。源码测试或可达性断言通过，不代表已完成原生视觉或无障碍验收；真实 Host 互通仍未验证。
